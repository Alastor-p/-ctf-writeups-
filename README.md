# CTF Writeups 知识库

面向数据/IT 从业者与 CTF 选手的**公开 writeup 归纳库**，覆盖国内外主流赛事（含 DEF CON）。本仓库只收录可公开查证的题目与解题思路摘要，并始终链接到原文；**不整篇照搬**原文。

> 第一批：强网杯 2025、CISCN 2025、DEF CON CTF Qualifier 2025。后续可继续追加网鼎杯、羊城杯等。

## 目录结构

```
ctf-writeups/
├── README.md                          # 本文件
├── <competition-slug>/<year>/
│   ├── README.md                      # 赛事概览 + 题目索引表
│   └── <category>/<challenge-slug>.md # 单题摘要
```

## 如何贡献

1. 按上述目录新建 `<slug>/<year>/<category>/<challenge>.md`。
2. 用自己的话写「考点」与「解题思路」，**关键代码只摘短片段**；完整 exploit 用链接指向原文。
3. 在对应年份的 `README.md` 题目表中增加一行，写明考点与 WP 链接。
4. **不要编造**未公开的题目、flag 或技术；找不到公开 WP 的题目在表中标注「暂无公开 WP」。
5. 提交前用浏览器或 `curl -I` 确认参考链接可达（丢弃 404）。
6. 中文撰写优先；英文原文可附中文摘要。
